            位运算与语义速记

            • SHARED_UNIT = 1 << 16，即每获得 1 个读锁，state 增加 65536
            • exclusiveCount(state) = state & 0xFFFF；sharedCount(state) = state >>> 16
            • 写锁可重入只增加低 16 位；读锁并发增加高 16 位
            • 读释放只有在总读计数归零时才返回 true，从而触发 releaseShared 的传播唤醒
            • setHeadAndPropagate 的触发判定：propagate > 0，或旧/新 head 为 null，或旧/新 head.waitStatus < 0
            • 读锁重入计数有三层：firstReader / cachedHoldCounter / ThreadLocalHoldCounter
            • 降级支持（写->读），升级不支持（读->写，可能自阻塞）
