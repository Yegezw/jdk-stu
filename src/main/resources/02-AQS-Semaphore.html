            扩展：CountDownLatch 如何使用 AQS（不参与本页流程）

            • 同步状态含义：AQS.state 表示剩余计数，初始值为 count
            • await() 路径：调用 acquireSharedInterruptibly(1)，tryAcquireShared 在 state==0 时返回 1，否则返回 -1 并进入共享队列等待
            • countDown() 路径：调用 releaseShared(1)，tryReleaseShared 通过 CAS 把 state 递减；仅当 state 递减到 0 时返回 true，触发 doReleaseShared 传播唤醒等待线程
            • 一次性语义：计数归零后闸门永久打开，CountDownLatch 不能重置
